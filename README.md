# **Delhi House Price Prediction 🏠💰**

This project aims to predict real estate prices in Delhi using various machine learning techniques. By analyzing factors such as area, location, and amenities, the model provides an estimated market value for residential properties.


# **📌 Project Overview**
Buying a home is one of the most significant financial decisions. This project leverages data science to help potential buyers and sellers estimate property prices in Delhi based on historical data. The project covers the end-to-end machine learning pipeline: from data cleaning and exploratory analysis to model deployment.


# **📊 Dataset Description**
The dataset contains information about various properties across Delhi with the following features:

Area: Total area of the property (in sq. ft.).

BHK: Number of Bedrooms, Hall, and Kitchen.

Bathroom: Number of bathrooms.

Furnishing: Type of furnishing (Furnished, Semi-Furnished, Unfurnished).
